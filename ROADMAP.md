# Roadmap

## v0.1

- Python breaking-change detection through Griffe.
- GitHub Action PR summaries and sticky comments.
- Release binaries for Linux, macOS, and Windows.

## Near Term

- `apibump.toml` configuration.
- Suppression rules for accepted breakages.
- Package autodetection from `pyproject.toml`.
- Better examples against real Python packages.

## Later

- Go backend through `golang.org/x/exp/apidiff`.
- Rust backend integration with `cargo-semver-checks`.
- Java backend exploration through JApiCmp.
- Monorepo package discovery.
